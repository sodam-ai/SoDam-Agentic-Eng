0. 이 도구가 무엇인가요 (한눈에)

소담 에이전틱은 "AI에게 일을 제대로 시키는 법"을 쉬운 한국어로 떠먹여 주는, Claude Code(또는 Codex)용 **플러그인(추가 기능)**입니다.

비유: AI는 공장의 기계, 당신은 그 공장을 설계하는 사람입니다. "알아서 해"가 아니라 무엇을·왜·어디까지 만들지 먼저 정하고, AI가 한 일을 검토하고, 위험한 건 자동으로 막습니다.

해주는 4가지:

기능 설명
온보딩 (F1) /sodam-agentic:start — AI에게 일 시키는 4단계(계획→실행→검토→안전)를 한국어로 안내
계획 먼저 (F2) 코드 짜기 전에 "①무엇을 ②왜 ③완성기준" 계획을 먼저 보여주고 승인받음
변경점 검토 (F3) 바꾼 내용을 "무엇을 / 왜 / 위험은?" 쉬운 말로 요약(많으면 읽기 전용 보조 AI에 위임)
안전 (F4) 위험 명령·비밀정보 노출·작업폴더 밖 쓰기·설정 파일 변경을 자동으로 막거나(deny) 확인(ask)받음, 확인·차단 이력은 F6으로 기록

💬 용어가 낯설다면: 플러그인=AI 프로그램에 기능을 더하는 부품 · 훅(hook)=AI가 뭘 하기 직전에 자동으로 끼어드는 감시장치 · 마켓플레이스=플러그인을 받아오는 "가게"(여기선 GitHub 주소) · 슬래시 명령=/로 시작하는 명령 · 세션=지금 이 대화창 하나(닫으면 끝) · MCP=AI가 외부 도구와 대화하는 규격(이 플러그인 자체는 MCP를 쓰지 않지만, .mcp.json이라는 설정 파일은 감시합니다 — §10 참고).

2. 필요 프로그램 다운로드·설치 (단계별)

2-1. Node.js 다운로드·설치

  1. https://nodejs.org 접속 → 초록색 "LTS" 버튼 클릭해 내려받기.
  2. 받은 설치 파일을 더블클릭 → "다음 → 다음 → 설치" (기본값 그대로 두면 됩니다).
  3. 설치 후 컴퓨터를 한 번 껐다 켜면 확실합니다.
  4. 확인: 터미널에 node -v → 버전이 뜨면 완료.

2-2. Claude Code 다운로드·준비

  • 이미 Claude Code를 쓰고 계신다면 건너뛰세요(지금 이 대화가 Claude Code입니다).
  • 처음이라면 공식 안내(https://code.claude.com)를 따라 설치하세요. (Node.js가 먼저 깔려 있어야 합니다.)

2-3. Codex 사용자라면

  • Codex CLI 자체 설치는 OpenAI 공식 안내를 따르세요. 이 플러그인은 Codex 설치 이후에 스킬을 추가하는 방식입니다 → §4 설치(Codex).

3. 빠른 시작 (3단계 골든패스)

  1. 설치: Claude Code 입력칸에 그대로 붙여넣고 Enter: 
    /plugin marketplace add https://github.com/sodam-ai/SoDam-Agentic-Eng
/plugin install sodam-agentic@sodam-agentic
  2. 시작: /sodam-agentic:start 입력 → 한국어 온보딩 안내가 뜹니다.
  3. 시키기: "○○ 만들어줘"라고 자연어로 부탁 → 계획이 먼저 뜨면 "네/진행"으로 승인 → 작업 완료 후 검토 요약 확인.

→ 여기까지 5분이면 "됐다" 경험이 끝납니다. 확인·진단 명령부터 앞세울 필요 없이, 그냥 시키는 게 먼저입니다.

  1. 이 저장소를 클론합니다: 
    git clone https://github.com/sodam-ai/SoDam-Agentic-Eng
  2. 내 프로젝트 폴더 안에서 설치 스크립트를 실행합니다(클론한 경로로 바꾸세요):

    ⚠️ 폴더 실수 주의: 터미널 도구에 따라 명령을 실행할 때마다 현재 위치가 사용자 홈 폴더로 초기화되는 경우가 있습니다. 반드시 작업하려는 프로젝트 폴더로 먼저 이동(cd)한 뒤 위 명령을 실행하세요. 그렇지 않으면 스킬·설정이 엉뚱한 폴더(예: 사용자 홈 폴더)에 설치됩니다.

⚠️ Codex에도 같은 안전 훅(F4)·안전 기록(F6)이 그대로 등록됩니다(F7, 2026-07-15 구현). 계획(F2)·검토(F3) 스킬도 동일하게 동작합니다. 다만 Codex 화면에서 확인(ask) 창이 실제로 뜨는지는 아직 사람이 직접 확인하지 않았습니다 — 자세히: §10 보안·데이터 흐름, §17 현재 개발 상태.

5. 실행·사용·작동 방법 (단계별)

실행(설치 직후 켜기):

  1. /sodam-agentic:start 입력 → "AI에게 일 시키는 4단계" 온보딩을 읽습니다.
  2. (권장) /init을 한 번 실행 → AI가 현재 폴더(프로젝트)를 인식합니다. 초보자가 가장 잘 건너뛰는 단계입니다.

사용(사람이 하는 것): 3. 자연어로 시키기: 예) "메모장 웹페이지 만들어줘". 확인·진단 명령부터 앞세울 필요 없습니다 — 그냥 시키는 게 먼저입니다. 4. 계획 확인: AI가 코드를 짜기 전에 "①무엇을 ②왜 ③완성기준" 계획을 보여주면, 읽고 **"네/진행"**으로 승인합니다. 5. 검토: 작업이 끝나면 "무엇을·왜 바꿨고 위험은?" 요약을 읽고 사람이 최종 판단합니다.

작동(내부에서 자동으로 일어나는 것): 6. AI가 파일을 쓰거나 명령을 실행하려는 매 순간마다, 소담의 안전 훅이 먼저 끼어들어 안전/확인/차단을 판정합니다(§9 아키텍처의 "판정 흐름" 참고). 사람이 아무것도 안 해도 항상 자동으로 동작합니다.

이 도구의 **아키텍처(구성요소·훅 실행 흐름)**가 궁금하면 → §9, 보안/데이터 흐름이 궁금하면 → §10.

6. 명령어 목록

명령 언제 쓰나
/sodam-agentic:start 처음 시작·온보딩 안내
/sodam-agentic:plan "계획 먼저" 기능을 직접 호출(보통은 자동 발동)
/sodam-agentic:review "변경점 검토" 기능을 직접 호출(보통은 자동 발동)
/sodam-agentic:log 막히거나(deny) 확인받은(ask) 기록 조회(F6)

형식은 /플러그인이름:명령입니다(2026-07-18부터 짧은 형태로 정리 — 예전엔 /sodam-agentic:sodam-agentic-start처럼 이름이 겹쳐 길었습니다). 새 대화창을 열고 /sodam-agentic:까지만 입력해도 4개가 목록으로 뜹니다.

7. 워크플로우 (작동 흐름)

[시작] /sodam-agentic:start  →  안전 켜짐 + 4단계 안내
   │
   ▼
[계획 먼저]  "만들어줘"  →  AI가 계획 제시  →  당신이 승인
   │
   ▼
[실행]  AI 작업  ──(위험 시)──▶  [안전]  자동 차단 / 확인
   │
   ▼
[검토]  무엇을·왜·위험  요약  →  당신이 판단  →  완료

발동 확인법(2026-07-26 추가): 계획 먼저(F2)가 실제로 작동하면 응답 맨 위에 🚀 소담 — 계획 먼저가, 변경점 검토(F3)가 작동하면 🔍 소담 — 변경점 검토가 뜹니다. 이 문구가 안 보이면 다른 스킬에 밀려 F2/F3가 발동하지 않은 것이니, 그 자리에서 "계획 먼저 보여줘" / "검토해줘"라고 직접 요청하면 됩니다.

핵심 원칙: "AI가 다 알아서"가 아니라, 사람이 운전석.

9. 아키텍처

이 플러그인은 서버·DB·로그인이 없는, 순수 로컬 도구입니다. 구성요소는 이렇습니다:

구성요소 파일 역할
매니페스트 .claude-plugin/plugin.json, marketplace.json Claude Code에 "이 폴더가 플러그인"이라고 알려주는 설명서
온보딩 (F1) commands/start.md /sodam-agentic:start 슬래시 명령 정의
계획·검토 (F2·F3) skills/plan/·skills/review/(자동 발동) + commands/plan.md·commands/review.md(수동 호출) 새 작업 요청·변경 완료 시 자동 발동 + 직접 호출도 가능
검토 보조 에이전트 agents/easy-reviewer.md 변경이 많을 때 F3가 위임하는 읽기 전용 서브 AI

10. 보안·데이터 흐름

  • 이 플러그인이 읽는 것: Claude Code가 실행하려는 도구 이름과 인자(예: 실행할 명령어 문자열, 쓰려는 파일 경로)뿐입니다. 이 정보는 표준입력(stdin)으로 훅에 전달됩니다. 그 외 파일 내용이나 대화 내용을 따로 들여다보지 않습니다.
  • 이 플러그인이 절대 하지 않는 것: 자체 네트워크 요청(외부 서버로 전송) · API 키·비밀번호·토큰 저장 또는 기록 · 외부 코드 자동 실행. (자기보안 자가검증 결과 0건 — hooks/_selftest.mjs)
  • 영구 데이터(F6): 안전 훅이 확인(ask)·차단(deny) 판정을 내릴 때만 ~/.sodamagentic/safety-log.jsonl(내 컴퓨터 사용자 폴더, 플러그인 개발 폴더 밖)에 한 줄씩 기록을 남깁니다. 기록 항목은 {판정, 대상, 이유, 시각}이며, 대상 문자열에 비밀값 패턴(API 키 등)이 있으면 저장 전 자동으로 [REDACTED]로 가립니다. 안전하게 통과한 작업은 기록하지 않습니다. 이 기록은 외부로 전송되지 않고 내 컴퓨터에만 남으며, 기록 자체가 실패해도 안전 판정(차단/확인)에는 영향을 주지 않습니다. 조회는 /sodam-agentic:log 명령입니다.

이 표는 이 저장소의 실제 코드(hooks/guard.mjs)에 있는 문구를 그대로 옮긴 것입니다 — 과장 없이, 실제 동작 그대로입니다. [소담 에이전틱] 접두사는 SoDamHarness 등 형제 플러그인과 동시 설치돼 훅이 함께 발동해도 어느 플러그인이 막았는지 바로 구분되도록 붙인 출처 표시입니다.

왜 .mcp.json이 특별히 중요한가: .mcp.json은 Claude Code가 폴더를 열 때 자동으로 시작할 프로그램(MCP 서버) 목록을 정의하는 파일입니다. 이 파일의 내용이 원치 않게 바뀌면, 다음에 이 폴더를 열 때 사용자가 의도하지 않은 프로그램이 자동으로 시작될 수 있습니다. 그래서 이 파일은 내용과 무관하게 항상 통째로 차단하고, 정말 필요하면 사용자가 직접 편집기로 열어 수정하도록 안내합니다. 일관성 보강: "AI에게 직접 명령어로 시켜서" 같은 방식으로도 위 판정을 피해 갈 수 없습니다 — 자연어로 부탁하든, 명령어를 직접 지정하든 동일한 기준으로 검사합니다.

11. 제거 방법 (Uninstall)

Claude Code:

  1. 입력칸에 /plugin uninstall sodam-agentic (또는 마켓플레이스 화면에서 제거 선택).
  2. 확인: /sodam-agentic를 쳐도 명령이 더는 안 뜨면 제거 완료.

Codex:

  • 설치가 "파일 복사" 방식이므로, 내 프로젝트의 .agents/skills/ 폴더에서 소담 관련 스킬 폴더를 직접 삭제하면 됩니다.

남는 데이터(중요): 플러그인을 제거해도 안전 기록 파일 ~/.sodamagentic/safety-log.jsonl은 자동으로 지워지지 않습니다(플러그인 폴더 밖, 사용자 홈 폴더에 저장되기 때문입니다). 완전히 지우고 싶으면 이 파일을 직접 삭제하세요. Codex를 함께 썼다면 프로젝트의 .codex/hooks.json에 등록된 항목(F7)도 제거 후 그대로 남으므로, 지우려면 해당 JSON의 PreToolUse 항목을 직접 삭제하면 됩니다.

13. FAQ (자주 묻는 질문)

Q. 이거 정말 안전한가요? A. 아니요, "100% 안전"은 아닙니다. "되돌릴 수 없는 위험은 막고, 나머지는 확인받는" 정도입니다. 최종 판단은 항상 사람이 합니다.

Q. 돈이 드나요? A. 이 플러그인 자체는 **무료(Apache-2.0)**입니다. 다만 Claude/Codex를 쓰는 비용(AI 모델 사용료)은 Anthropic·OpenAI 약관을 따로 따릅니다.

Q. Codex에서도 Claude Code와 똑같이 안전한가요? A. 같은 안전장치가 Codex에도 등록됩니다(F7). 계획(F2)·검토(F3)·차단·안전 기록(F6)까지 같은 로직을 씁니다. 다만 Codex에서 "확인해도 될까요?" 창이 실제로 뜨는지는 아직 사람이 직접 확인하지 않았습니다 — 100% 동등하다고 단정하지 않고 정직하게 남겨둡니다.

Q. 막히거나 확인받은 기록을 나중에 다시 볼 수 있나요? A. 됩니다. /sodam-agentic:log 명령으로 최근 기록을 쉬운 한국어로 볼 수 있습니다. 단, 안전하게 통과한 작업은 기록되지 않고 막히거나(deny) 확인받은(ask) 것만 남습니다. 기록은 내 컴퓨터에만 저장되고 어디로도 전송되지 않습니다.

Q. SoDamHarness 없이 써도 되나요? A. 됩니다. Harness가 없으면 이 플러그인의 "최소 안전 폴백"이 전체 모드로 작동합니다. 다만 자동 백업·되돌리기 같은 더 강한 기능은 Harness가 있어야 합니다.

Q. 상업적으로 써도 되나요? A. 이 플러그인 자체는 Apache-2.0이라 상업 사용·재배포·서비스 운영 모두 가능합니다(NOTICE 파일 보존 조건). 단 Claude/Codex 모델 사용의 상업 조건은 각 제공사 약관을 확인하세요. 자세히 → §15 라이선스.

Q. 다른 5개 형제 플러그인도 꼭 설치해야 하나요? A. 아니요. 이 플러그인 혼자서도 최소 안전으로 작동합니다. 다만 SoDamHarness와 같이 쓰면 더 강력해집니다 → §18 소담 패밀리.

Q. 제가 시킨 작업 내용이 어딘가로 전송되나요? A. 이 플러그인 자체는 네트워크 요청을 보내지 않습니다(§10). Claude Code/Codex 자체가 AI 모델과 통신하는 것과는 별개입니다. (안전 기록(F6)은 전송이 아니라 내 컴퓨터 파일에 저장하는 것입니다.)

Q. .mcp.json을 왜 무조건 막나요? 제가 진짜 MCP 서버를 추가하고 싶으면요? A. 이 파일을 편집기로 직접(사람이 손으로) 여시면 됩니다. 이 플러그인이 막는 건 "AI가 자동으로 이 파일을 대신 바꾸는 것"만입니다 — 왜 위험한지는 §10 참고.

14. 안전 주의사항 (꼭 지키기)

  • 비밀번호·API 키·.env 같은 비밀정보를 코드·문서·채팅 어디에도 넣지 마세요.
  • 안전장치는 "되돌릴 수 없는 위험은 막고, 나머지는 확인받는" 방식입니다. "100% 안전"이 아닙니다 — 마지막 판단은 사람이 합니다.
  • 새로 받은 외부 파일·도구를 AI가 자동 실행하지 않게 주의하세요.
  • 화면 아래 자동 승인(auto-accept/bypass permissions) 모드가 켜져 있으면 확인창이 조용히 통과됩니다 — 안전하게 쓰려면 Shift+Tab으로 "매번 물어봄" 모드를 권장합니다.
  • 막히거나(deny) 확인받은(ask) 기록은 /sodam-agentic:log로 나중에 다시 볼 수 있습니다(안전하게 통과한 작업은 기록 안 됨, 내 컴퓨터에만 저장).

  • ⚠️ 아직 사람이 직접 확인해야 하는 것(정직하게 밝힙니다):
    1. .mcp.json 차단이 실제 Claude Code 화면에서도 확인창 없이 즉시 막히는지 (코드·자가검증은 완료, 화면 재현만 남음)
    2. 폴더 통째 삭제 같은 치명 명령이 "묻지도 따지지도 않고 바로 차단"되는지 실제 화면 재확인
    3. 계획 먼저(F2)·변경점 검토(F3)의 발동 마커(🚀/🔍)가 완전히 새로운 작업에서도 매번 뜨는지
    4. Codex에서 "확인(ask)" 창이 실제로 화면에 뜨는지(F7)
    5. (공개 배포를 고려할 때만 필요) 비개발자 베타 테스트·상표 관련 법무 최종 확인 — 지금은 개인용이라 필수 전제조건 아님
  • 개인용 확정(2026-07-15): 이 도구는 개발자 본인이 직접 실제 사용하려고 만든 개인용 도구입니다. 위 5번(베타·법무)은 지금 당장은 필수 조건이 아니며, 추후 공개 공유를 고려할 때 다시 필요해집니다. 과장하지 않고 있는 그대로 안내합니다.
