# 소담 시작 — AI에게 제대로 일 시키기

사용자가 이 명령을 실행하면, 아래를 **쉬운 한국어로, 비개발자 기준**으로 안내하세요. 전문 용어는 풀어서 설명하고, 한 번에 다 쏟지 말고 짧게.

## 1) 한 문장 비유 (먼저)

> "AI는 공장의 기계이고, 당신은 그 공장을 **설계하는 사람**입니다. 기계에 그냥 '알아서 해'가 아니라, **무엇을·왜·어디까지** 만들지 지시서를 먼저 줍니다."

이게 이 도구의 핵심입니다. **AI가 다 알아서가 아니라, 사람이 운전석에 앉습니다.**

## 2) AI에게 제대로 일 시키는 4단계

1. **계획 먼저** — 코드를 짜기 전에, AI가 "무엇을·왜·완성 기준"을 한국어로 먼저 보여주고 당신의 승인을 받습니다.
2. **실행** — 승인하면 AI가 작업합니다.
3. **검토** — 끝나면 "무엇을 바꿨나 / 왜 / 위험은 없나"를 쉬운 말로 요약해 줍니다. 당신이 감리합니다.
4. **안전** — 위험한 명령(폴더 통째 삭제, API 키 노출 등)은 자동으로 막거나 확인을 요청합니다.

## 3) 안전 상태 점검 (정직하게 안내)

- 이 플러그인은 **최소 안전 폴백**을 가지고 있습니다(위험명령·키 노출·작업폴더 밖 쓰기·설정파일 변경 4종 차단).
- 더 강한 일반 안전(백업·되돌리기)은 별도 플러그인 **SoDamHarness**가 담당합니다. 아직 설치/완성 전이면, 이 플러그인의 폴백이 **전체 모드로 작동**합니다(안전 우선).
- ⚠️ **가장 중요한 한계 — 자동 승인 모드:** 화면 아래에 `auto-accept` 또는 `bypass permissions` 표시가 있으면 **안전 확인(ask)이 조용히 자동 통과**되어 이 플러그인의 보호가 약해집니다. 안전하게 쓰려면 **`Shift+Tab`으로 "매번 물어봄" 모드**로 두라고 안내하세요. (플러그인 훅은 이 모드를 스스로 감지할 수 없으니, 사람이 직접 확인해야 합니다.)
- ⚠️ 과장하지 마세요. "100% 안전"이라고 말하지 말고, "되돌릴 수 없는 위험은 막고, 나머지는 확인을 받는다"고 정확히 안내하세요.

## 4) 첫 작업 전에 (왕초보가 가장 잘 건너뛰는 것)

- **`/init` 을 먼저 한 번 실행**하라고 안내하세요. 안 하면 AI가 이 프로젝트가 뭔지 모르는 채로 일합니다.

## 5) 초보자 3대 실수 카드 (예방)

1. 바로 "만들어줘" → ❌. **계획서(무엇을·왜·완성기준)를 먼저** 받으세요.
2. 결과를 확인 안 함 → ❌. **검토 요약을 읽고** 위험을 직접 고르세요.
3. 한 번에 너무 많이 → ❌. **작게 쪼개서** 시키세요.
