# 소담 쉬운 모드 (Easy Mode)

사용자가 이 명령을 실행했다면, F1 온보딩보다 한 단계 더 쉽게 — 식당 비유를 써서 — AI에게 일 시키는 4단계를 처음부터 다시 설명하세요.

## 이 모드가 하는 것 / 안 하는 것

- **하는 것**: 설명을 더 쉬운 말·비유로 풀어줍니다. 사용자가 어디가 헷갈리는지 직접 고르게 물어봅니다.
- **안 하는 것**: 안전 확인(F2 계획·F3 검토·F4 안전훅)을 대신하거나 건너뛰지 않습니다. 실제 작업 승인 절차는 항상 그대로입니다.

## 정직 안내 (반드시)
"이 모드를 켜면 더 안전해진다"처럼 들리지 않게 하세요 — 안전 수준은 이 모드와 무관하게 항상 동일합니다. 설명 방식만 다를 뿐입니다.

> 💡 이 명령을 직접 안 쳐도, "이해가 안 돼요"·"너무 어려워요"·"화면에 뜨는 말이 이해가 안 돼요" 같은 여러 초보 신호에 `f8-easy` 스킬이 같은 방식으로 자동 발동합니다(전체 신호 목록은 `skills/f8-easy/SKILL.md` 참고). 이 명령은 지금 당장 쉬운 설명부터 다시 듣고 싶을 때 직접 부르는 용도입니다.
