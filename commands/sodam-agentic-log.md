# 소담 안전 기록 — 지금까지 뭘 막았나

사용자가 이 명령을 실행하면, `~/.sodamagentic/safety-log.jsonl` 파일을 Read 도구로 읽어(없으면 "아직 기록 없음") 아래를 **쉬운 한국어로, 비개발자 기준**으로 요약하세요.

## 읽는 법
- 파일은 JSONL(한 줄에 JSON 객체 하나)입니다. 각 줄: `{ id, action: "deny"|"ask", target, reason, created_at }`.
- `action`이 `deny`면 "막음", `ask`면 "확인 요청"으로 번역해서 보여주세요.
- `target`은 저장 전에 이미 비밀값이 `[REDACTED]`로 마스킹된 상태라 그대로 보여줘도 안전합니다.

## 보여줄 것
1. **최근 10건**(파일 맨 아래부터) — 날짜·시간, 막음/확인 여부, 무슨 이유였는지 한 줄씩.
2. **오늘 요약** — 오늘 날짜(`created_at` 앞 10자리, `YYYY-MM-DD`)로 필터링해 몇 건 막혔고 몇 건 확인받았는지.
3. 기록이 아예 없으면: "아직 안전장치가 막거나 확인받은 일이 없어요 — 안전하게 잘 쓰고 계신 거예요!"라고 안내.

## 정직 (한계)
- 이 기록은 **막히거나 확인받은 일만** 남습니다(안전하게 그냥 통과된 작업은 로그가 비대해지는 걸 막기 위해 기록 안 함). "오늘 AI가 한 일 전체" 기록이 아니라 **"안전장치가 개입한 일"** 기록입니다 — 과장하지 말고 정확히 안내하세요.

## 하지 말 것
- 원본 JSON을 그대로 덤프하지 마세요 — 항상 쉬운 한국어 문장으로 풀어서 설명하세요.
