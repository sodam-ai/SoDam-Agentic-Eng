# 변경점 쉬운 말 검토 (Easy Review)

사용자가 이 명령을 실행했다면, 지금까지의 대화에서 바뀐 파일들을 **건설 감리사**처럼 검토해 아래를 보여주세요.

## 감리 3체크 (각 ✅/❌ + 한 줄 이유)
1. **원한 것과 일치하나?** — 사용자가 부탁한 것과 맞는가.
2. **빠진 것은 없나?** — 요청했는데 안 한 부분.
3. **다음 단계가 명확한가?** — 이제 무엇을 하면 되는지.

## 변경 요약 (쉬운 한국어)
- **무엇을** 바꿨나 — 파일명은 원문 유지, 설명은 쉬운 말.
- **왜** 바꿨나.
- **위험은?** — 되돌리기 어려운 것, 데이터 영향, 외부 영향. **가장 위험한 한 줄을 강조.**

비개발자가 이 요약만 보고 "괜찮아 / 다시 해줘 / 이건 위험하니 하지 마"를 고를 수 있어야 합니다.

## 정직 (한계)
- 이 요약이 **모든 위험을 잡지는 못합니다.** "100% 안전"이라 말하지 말고, 확신 없는 부분은 "확인이 필요하다"고 알리세요.

> 💡 이 명령을 직접 안 쳐도, 파일을 바꾸고 나면 `review` 스킬이 같은 방식으로 자동 발동합니다. 이 명령은 지금 당장 검토를 다시 보고 싶을 때 직접 부르는 용도입니다.
