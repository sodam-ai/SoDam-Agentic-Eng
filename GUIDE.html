0. 이 도구가 무엇인가요? (한 문장)

소담은 "AI에게 일을 제대로 시키는 법"을 쉬운 한국어로 떠먹여 주는, Claude Code/Codex용 **플러그인(추가 기능)**입니다.

비유: AI는 공장의 기계, 당신은 그 공장을 설계하는 사람입니다. "알아서 해"가 아니라 무엇을·왜·어디까지 만들지 먼저 정하고, AI가 한 일을 검토하고, 위험한 건 막습니다.

해주는 4가지: | 기능 | 한 줄 설명 | |---|---| | 온보딩 | AI에게 일 시키는 4단계를 한국어로 안내 | | 계획 먼저 | 코드 짜기 전에 "무엇을·왜·완성기준" 계획을 먼저 보여주고 승인받음 | | 변경점 검토 | 바꾼 내용을 "무엇을 / 왜 / 위험은?"으로 쉽게 요약 | | 안전 | 위험 명령·비밀번호 노출·엉뚱한 위치 쓰기·설정 변경을 자동으로 막거나 확인 |

💬 용어가 낯설다면: 플러그인=AI 프로그램에 기능을 더하는 부품 · 훅(hook)=AI가 뭘 하기 직전에 자동으로 끼어드는 감시장치 · 마켓플레이스=플러그인을 받아오는 "가게"(여기선 GitHub 주소) · 슬래시 명령=/로 시작하는 명령 · 세션=지금 이 대화창 하나(닫으면 끝) · MCP=AI가 외부 도구와 대화하는 규격(이 플러그인은 사용하지 않음).

5. 실행·사용·작동 방법 (단계별)

  1. /sodam-agentic-start 입력 → "AI에게 일 시키는 4단계" 온보딩을 읽습니다.
  2. (권장) /init 을 한 번 실행 → AI가 현재 폴더(프로젝트)를 인식합니다. 초보자가 가장 잘 건너뜁니다.
  3. 자연어로 시키기: 예) "메모장 웹페이지 만들어줘". (확인·진단 명령부터 앞세울 필요 없습니다 — 그냥 시키는 게 먼저입니다.)
  4. 계획 확인: AI가 코드 전에 "①무엇을 ②왜 ③완성기준" 계획을 보여주면, 읽고 "네/진행" 으로 승인.
  5. 검토: 작업이 끝나면 "무엇을·왜 바꿨고 위험은?" 요약을 읽고 판단.
  6. 안전: 위험한 명령(폴더 통째 삭제 등)을 시키면 자동으로 막거나 "확인할까요?" 묻습니다.

9. 아키텍처

이 플러그인은 서버·DB·로그인이 없는, 순수 로컬 도구입니다. 구성요소는 이렇습니다:

구성요소 파일 역할
매니페스트 .claude-plugin/plugin.json, marketplace.json Claude Code에 "이 폴더가 플러그인"이라고 알려주는 설명서
온보딩 (F1) commands/sodam-agentic-start.md /sodam-agentic-start 슬래시 명령 정의
계획·검토 (F2·F3) skills/sodam-agentic-plan/, skills/sodam-agentic-review/ 새 작업 요청·변경 완료 시 자동 발동하는 안내 규칙
검토 보조 에이전트 agents/easy-reviewer.md 변경이 많을 때 F3가 위임하는 읽기 전용 서브 AI
안전 훅 (F4) hooks/hooks.json(배선표) + hooks/guard.mjs(판정 로직) + hooks/delegate.mjs(형제 감지) Bash·PowerShell·Write·Edit 실행 직전에 항상 개입
안전 규칙 데이터 data/agentic-rules.json 코드 수정 없이 조정 가능한 규칙 값
Codex 지원 (F5) codex/install.mjs 마켓플레이스가 없는 Codex용 별도 설치기(스킬을 파일로 복사)

안전 훅(F4) 판정 흐름

Claude Code가 도구(Bash·Write·Edit 등)를 실행하려는 순간
        │
        ▼
   hooks/guard.mjs 가 먼저 판정 (PreToolUse = "실행 직전")
        │
        ├─ 안전(safe)          → 그냥 통과
        ├─ 확인 필요(ask)       → "정말 진행할까요?" 질문
        ├─ 위험(deny)          → "막았어요" (형제 SoDamHarness가 있으면 겹치는 항목은 위임)
        └─ 치명(catastrophic)  → "막았어요" (형제 유무와 **무관하게 항상** 차단)
  • hooks/delegate.mjs의 isHarnessAlive()가 형제 플러그인 SoDamHarness의 존재를 확인합니다.
  • Harness가 있으면 "겹치는" 위험(재귀 삭제·민감 경로 등)은 Harness에 넘겨 확인창이 두 번 뜨지 않게 합니다(Harness는 자동 백업·되돌리기까지 더해줍니다).
  • 단, 되돌릴 수 없는 치명 명령(디스크 초기화급)은 Harness 설치 여부와 무관하게 이 플러그인도 항상 자체적으로 막습니다 — 형제가 없거나 고장 났을 때를 대비한 이중 안전장치입니다.

10. 보안·데이터 흐름

  • 이 플러그인이 읽는 것: Claude Code가 실행하려는 도구 이름과 인자(예: 실행할 명령어 문자열, 쓰려는 파일 경로)뿐입니다. 이 정보는 표준입력(stdin)으로 훅에 전달됩니다. 그 외 파일 내용이나 대화 내용을 따로 들여다보지 않습니다.
  • 이 플러그인이 절대 하지 않는 것: 자체 네트워크 요청(외부 서버로 전송) · API 키·비밀번호·토큰 저장 또는 기록 · 외부 코드 자동 실행. (자기보안 자가검증 결과 0건 — hooks/_selftest.mjs)
  • 영구 데이터: 현재 버전은 별도의 설정·로그·백업 파일을 만들지 않습니다(안전 판정은 매번 그 순간 즉시 이뤄지고 저장되지 않음). Phase 2에서 "안전 기록 조회(F6)"가 추가되면 이 절이 갱신됩니다.

실제 판정 3단계 예시

단계 예시 상황 실제로 뜨는 안내(요약)
✅ 안전(통과) echo hello, 새 파일 만들기 (아무 메시지 없이 그냥 진행)
❓ 확인(ask) 파일 하나 삭제, .claude/settings.json 수정, 작업폴더 밖 쓰기 "되돌리기 어려운 작업이에요… 정말 진행할까요?"
⛔ 차단(deny) API 키 노출 시도 "API 키·비밀값이 노출될 수 있는 작업이라 막았어요…"
⛔ 차단(deny) 폴더 통째 삭제 "폴더를 통째로 지우는 작업은 안전하게 막았어요…"
⛔ 차단(항상, 치명) 디스크 초기화급 명령, curl 주소 | bash(인터넷 코드 확인 없이 바로 실행) "되돌릴 수 없는 위험한 명령이라 막았어요…"

이 표는 이 저장소의 실제 코드(hooks/guard.mjs)에 있는 문구를 그대로 옮긴 것입니다 — 과장 없이, 실제 동작 그대로입니다.

일관성 보강(2026-07-12): "AI에게 직접 명령어로 시켜서" 같은 방식으로도 위 판정을 피해 갈 수 없습니다 — 자연어로 부탁하든, 명령어를 직접 지정하든 동일한 기준으로 검사합니다.

11. 제거 방법 (Uninstall)

Claude Code:

  1. 입력칸에 /plugin uninstall sodam-agentic (또는 마켓플레이스 화면에서 제거 선택).
  2. 확인: /sodam-agentic 를 쳐도 명령이 더는 안 뜨면 제거 완료.

Codex:

  • 설치가 "파일 복사" 방식이므로, 내 프로젝트의 .agents/skills/ 폴더에서 소담 관련 스킬 폴더를 직접 삭제하면 됩니다.

남는 데이터: 이 플러그인은 현재 별도의 영구 설정·로그·백업 파일을 만들지 않으므로, 제거 후 컴퓨터에 남는 파일이 없습니다. (향후 안전 기록 기능이 추가되면 이 절을 갱신합니다.)

16. FAQ (자주 묻는 질문)

Q. 이거 정말 안전한가요? A. 아니요, "100% 안전"은 아닙니다. "되돌릴 수 없는 위험은 막고, 나머지는 확인받는" 정도입니다. 최종 판단은 항상 사람이 합니다.

Q. 돈이 드나요? A. 이 플러그인 자체는 무료(Apache-2.0)입니다. 다만 Claude/Codex를 쓰는 비용(모델 사용료)은 Anthropic·OpenAI 약관을 따로 따릅니다.

Q. Codex에서도 Claude Code와 똑같이 안전한가요? A. 아니요. 계획(F2)·검토(F3)는 되지만, 안전 훅(F4)은 Codex에서 Claude Code만큼 강하지 않습니다(Phase 2에서 보강 예정).

Q. SoDamHarness 없이 써도 되나요? A. 됩니다. Harness가 없으면 이 플러그인의 "최소 안전 폴백"이 전체 모드로 작동합니다. 다만 자동 백업·되돌리기 같은 더 강한 기능은 Harness가 있어야 합니다.

Q. 상업적으로 써도 되나요? A. 이 플러그인 자체는 Apache-2.0이라 상업 사용·재배포·서비스 운영 모두 가능합니다(NOTICE 파일 보존 조건). 단 Claude/Codex 모델 사용의 상업 조건은 각 제공사 약관을 확인하세요.

Q. 다른 5개 형제 플러그인도 꼭 설치해야 하나요? A. 아니요. 이 플러그인 혼자서도 최소 안전으로 작동합니다. 다만 SoDamHarness와 같이 쓰면 더 강력해집니다(README의 "소담 패밀리" 표 참고).

Q. 제가 시킨 작업 내용이 어딘가로 전송되나요? A. 이 플러그인 자체는 네트워크 요청을 보내지 않습니다(§10 보안·데이터 흐름 참고). Claude Code/Codex 자체가 AI 모델과 통신하는 것과는 별개입니다.
