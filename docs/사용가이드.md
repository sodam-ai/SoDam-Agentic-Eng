# 소담 에이전틱 (SoDamAgentic) — 사용 가이드 (왕초보용)

> 🇰🇷 한국어 가이드 (기본) · 영어 가이드: [USER-GUIDE.en.md](./USER-GUIDE.en.md)
> 이 가이드는 **AI·컴퓨터·스마트폰·전자기기를 처음 다루는 분**도 그대로 따라 할 수 있게 만들었습니다.
> ⚠️ **현재 상태:** Phase 1 (초기 버전, MVP). 일부 기능은 아직 다듬는 중입니다(맨 끝 "개발 상태" 참고).

## 0. 이 도구가 무엇인가요? (한 문장)

> **소담**은 "AI에게 일을 제대로 시키는 법"을 **쉬운 한국어로 떠먹여 주는**, Claude Code/Codex용 **플러그인(추가 기능)**입니다.

비유: **AI는 공장의 기계, 당신은 그 공장을 설계하는 사람**입니다. "알아서 해"가 아니라 **무엇을·왜·어디까지** 만들지 먼저 정하고, AI가 한 일을 검토하고, 위험한 건 막습니다.

**해주는 4가지:**
| 기능 | 한 줄 설명 |
|---|---|
| 온보딩 | AI에게 일 시키는 4단계를 한국어로 안내 |
| 계획 먼저 | 코드 짜기 전에 "무엇을·왜·완성기준" 계획을 먼저 보여주고 승인받음 |
| 변경점 검토 | 바꾼 내용을 "무엇을 / 왜 / 위험은?"으로 쉽게 요약 |
| 안전 | 위험 명령·비밀번호 노출·엉뚱한 위치 쓰기·설정 변경을 자동으로 막거나 확인 |

3. **시키기:** "○○ 만들어줘"라고 부탁 → **계획**이 먼저 뜨면 "네" → 작업 → **검토 요약** 확인.

→ 여기까지 5분이면 "됐다" 경험 완료.

## 5. 실행·사용·작동 방법 (단계별)

1. **`/sodam-agentic-start`** 입력 → "AI에게 일 시키는 4단계" 온보딩을 읽습니다.
2. (권장) **`/init`** 을 한 번 실행 → AI가 현재 폴더(프로젝트)를 인식합니다. *초보자가 가장 잘 건너뜁니다.*
3. **자연어로 시키기:** 예) "메모장 웹페이지 만들어줘".
4. **계획 확인:** AI가 코드 전에 "①무엇을 ②왜 ③완성기준" 계획을 보여주면, 읽고 **"네/진행"** 으로 승인.
5. **검토:** 작업이 끝나면 "무엇을·왜 바꿨고 위험은?" 요약을 읽고 판단.
6. **안전:** 위험한 명령(폴더 통째 삭제 등)을 시키면 자동으로 막거나 "확인할까요?" 묻습니다.

## 9. 문제·오류 대처

| 증상 (이렇게 보임) | 왜 (원인) | 이렇게 (해결) |
|---|---|---|
| `/sodam-agentic` 쳐도 안 뜸 | 설치 안 됨 | `/plugin install sodam-agentic@sodam` 다시 |
| 설치할 때 "권한 없음/접근 불가" | 비공개 저장소 권한 없음 | 본인 GitHub 계정 로그인·접근 권한 확인 |
| "Node가 없다"고 나옴 | Node.js 미설치 | 2-1 따라 Node.js 18+ 설치 후 재시도 |
| 한글이 `□□□`로 깨짐 | 글자 표시 문제 | 화면 캡처해서 문의 (영문 버전 안내 가능) |
| 계획 없이 바로 코드부터 짬 | 초기 버전 한계(자동발동 미보장) | 정상일 수 있음 — 알려주시면 보강 |
| 위험 명령이 안 막힘 | 안전 훅 미작동 | 캡처해서 문의 (Node·설치 상태 점검) |
| 명령어가 옛 이름으로 보임 | 설치본 캐시 | `/plugin marketplace update sodam` → 재설치 |
