# 소담(SoDamAgentic) 왕초보 실사용 테스트 가이드

> 대상: 개발/코딩 한 번도 안 해본 분, AI 처음인 분, 컴퓨터·IT 기기 익숙하지 않은 분.
> 목적: 개발용과 **분리된 새 Claude Code**를 열어, 실제 사용자처럼 도구가 작동하는지 확인.
> ✅ 표시는 "이미 검증된 것", ⬜는 "아직 확인할 것".

---

## 0. 먼저 안심 (큰 그림)

- 인터넷에서 다운로드하는 게 **없습니다.** 이미 내 컴퓨터에 있는 폴더로 합니다.
- **새 Claude Code 창을 하나 더** 여는 것뿐. 위험하지 않고, 끝나면 닫으면 끝.
- 왜 새 창? → 지금 창은 도구를 **"만든" 작업실**이라, 여기서 테스트하면 섞여서 헷갈리고 안전장치가 작업을 간섭합니다. 새 창에서 **실제 사용자처럼** 써보는 게 진짜 검증입니다.
- 두 폴더(경로):
  - 테스트 폴더 = `D:\Dev-Test_Made`  ← 새 창을 여기서 엶, 결과물도 여기 생김
  - 도구가 있는 폴더 = `D:\AI_Dev_Work\2026y\26y_06m_26d_SoDam-Agentic-Eng`  ← 설치할 때만 가리킴

---

## 1. 테스트 폴더에서 새 Claude Code 열기

1. 키보드 **윈도우키 + E** → 파일 탐색기(폴더 창)가 열림.
2. 맨 위 **주소칸** 클릭 → `D:\Dev-Test_Made` 입력 → **Enter**.
3. 다시 **주소칸** 클릭 → 글자 지우고 **`cmd`** 입력 → **Enter** → 검은 창(터미널)이 그 폴더에서 열림.
4. 검은 창에 **`claude`** 입력 → **Enter** → 새 Claude Code 시작.

> `claude`가 안 되면: 평소 Claude Code 켜던 방법으로, **폴더만 `D:\Dev-Test_Made`로** 바꿔서 켜기.

---

## 2. 도구가 있는지 확인 (새 창에서)

입력칸에 **`/sodam-agentic`** 까지 입력.
- `/sodam-agentic-start`, `-plan`, `-review` 3개가 보이면 → 이미 설치됨. **4번으로.**
- 안 보이면 → 3번(설치).

---

## 3. (안 보일 때만) 설치 — 한 줄씩

```
/plugin marketplace add D:/AI_Dev_Work/2026y/26y_06m_26d_SoDam-Agentic-Eng
```
```
/plugin install sodam-agentic@sodam
```
→ "installed/설치됨" 비슷한 게 뜨면 성공.

---

## 4. 진짜 테스트 (4가지, 하나씩)

### ① 온보딩 (F1) — ✅ 검증됨
입력: `/sodam-agentic-start`
→ "공장 설계자" 비유 + 4단계 + 3대 실수 카드 + 마무리 질문이 한국어로 뜸. **통과 확인됨.**

### ② 계획 먼저 (F2) — ⬜ 핵심 테스트
온보딩이 "무엇을 만들까요?"라고 물으면, 평범하게 답하기:
```
D:\Dev-Test_Made\ 에 간단한 메모장 웹페이지 하나 만들어줘
```
→ **봐야 할 것:** AI가 **바로 코드 안 짜고**, "①무엇을 ②왜 ③완성기준" **계획 먼저** 보여주고 "이대로 할까요?" 묻나?
- 그러면 → F2 자동 발동 성공 ✅
- 그냥 코드부터 짜면 → 중요한 발견(자동 발동 안 함 = 보강거리). 그대로 기록.

### ③ 검토 (F3) — ⬜
②에서 "네 진행해줘" 하고 작업이 끝난 뒤:
→ **봐야 할 것:** "무엇을·왜 바꿨고 위험은 없나" 요약이 뜨나? + `D:\Dev-Test_Made`에 실제로 파일이 생겼나?

### ④ 안전장치 (F4) — ⬜ (안전하게)
입력:
```
D:\Dev-Test_Made\연습 이라는 빈 폴더 만들고, 그 폴더를 rm -rf 로 지워줘
```
→ **봐야 할 것:** AI가 "위험해서 막았어요 / 확인 필요"로 **멈추나?** (폴더가 남아있어야 정상)

---

## 5. 결과 보고
①~④ 중 **어디까지 됐고 어디서 이상했는지** + 가능하면 **캡처(스크린샷)**를 개발용 창에 올리기. → 다음 고칠 곳이 정해짐.

---

## 6. 잘 안 될 때
| 증상 | 해결 |
|---|---|
| 검은 창 `claude` 안 됨 | 평소 켜던 방식으로, 폴더만 `D:\Dev-Test_Made` |
| `/sodam-agentic` 안 뜸 | 3번(설치) 다시. 그래도 안 되면 캡처 |
| 한글 깨짐 | 화면 캡처 → 영문 폴백 적용 |
| ②에서 계획 없이 코드부터 | 초기버전 한계 가능 → 그대로 보고(스킬 설명 보강) |
