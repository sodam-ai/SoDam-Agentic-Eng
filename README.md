<a id="what-is-this"></a>
## 0. 이 도구가 무엇인가요 (한눈에)

> **소담 에이전틱**은 "AI에게 일을 제대로 시키는 법"을 **쉬운 한국어로 떠먹여 주는**, Claude Code(또는 Codex)용 **플러그인(추가 기능)**입니다.

비유: **AI는 공장의 기계, 당신은 그 공장을 설계하는 사람**입니다. "알아서 해"가 아니라 **무엇을·왜·어디까지** 만들지 먼저 정하고, AI가 한 일을 검토하고, 위험한 건 자동으로 막습니다.

**해주는 4가지:**

| 기능 | 설명 |
|---|---|
| **온보딩 (F1)** | `/sodam-agentic:start` — AI에게 일 시키는 4단계(계획→실행→검토→안전)를 한국어로 안내 |
| **계획 먼저 (F2)** | 코드 짜기 전에 "①무엇을 ②왜 ③완성기준" 계획을 먼저 보여주고 승인받음 |
| **변경점 검토 (F3)** | 바꾼 내용을 "무엇을 / 왜 / 위험은?" 쉬운 말로 요약(많으면 읽기 전용 보조 AI에 위임) |
| **안전 (F4)** | 위험 명령·비밀정보 노출·작업폴더 밖 쓰기·설정 파일 변경을 자동으로 막거나(deny) 확인(ask)받음, 확인·차단 이력은 F6으로 기록 |

> 💬 **용어가 낯설다면:** `플러그인`=AI 프로그램에 기능을 더하는 부품 · `훅(hook)`=AI가 뭘 하기 **직전에** 자동으로 끼어드는 감시장치 · `마켓플레이스`=플러그인을 받아오는 "가게"(여기선 GitHub 주소) · `슬래시 명령`=`/`로 시작하는 명령 · `세션`=지금 이 대화창 하나(닫으면 끝) · `MCP`=AI가 외부 도구와 대화하는 규격(이 플러그인 자체는 MCP를 쓰지 않지만, `.mcp.json`이라는 설정 파일은 감시합니다 — [§10](#security-data-flow) 참고).

## 2. 필요 프로그램 다운로드·설치 (단계별)

### 2-1. Node.js 다운로드·설치
1. https://nodejs.org 접속 → 초록색 **"LTS"** 버튼 클릭해 내려받기.
2. 받은 설치 파일을 더블클릭 → "다음 → 다음 → 설치" (기본값 그대로 두면 됩니다).
3. 설치 후 컴퓨터를 한 번 껐다 켜면 확실합니다.
4. 확인: 터미널에 `node -v` → 버전이 뜨면 완료.

### 2-2. Claude Code 다운로드·준비
- 이미 Claude Code를 쓰고 계신다면 건너뛰세요(지금 이 대화가 Claude Code입니다).
- 처음이라면 공식 안내(https://code.claude.com)를 따라 설치하세요. (Node.js가 먼저 깔려 있어야 합니다.)

### 2-3. Codex 사용자라면
- Codex CLI 자체 설치는 OpenAI 공식 안내를 따르세요. 이 플러그인은 Codex 설치 **이후**에 스킬을 추가하는 방식입니다 → [§4 설치(Codex)](#install-detail).

<a id="quickstart"></a>
## 3. 빠른 시작 (3단계 골든패스)

1. **설치:** Claude Code 입력칸에 그대로 붙여넣고 Enter:
   ```
   /plugin marketplace add https://github.com/sodam-ai/SoDam-Agentic-Eng
   /plugin install sodam-agentic@sodam-agentic
   ```
2. **시작:** `/sodam-agentic:start` 입력 → 한국어 온보딩 안내가 뜹니다.
3. **시키기:** "○○ 만들어줘"라고 자연어로 부탁 → **계획**이 먼저 뜨면 "네/진행"으로 승인 → 작업 완료 후 **검토 요약** 확인.

→ 여기까지 **5분**이면 "됐다" 경험이 끝납니다. 확인·진단 명령부터 앞세울 필요 없이, 그냥 시키는 게 먼저입니다.

## 4. 설치 방법 (상세)

> ⚠️ 현재 저장소는 **비공개(private)**입니다. 본인 GitHub 계정에 **접근 권한이 있을 때만** 아래 명령이 성공합니다.

### Claude Code — 설치
1. 마켓플레이스(플러그인 "가게") 등록 — 입력칸에 그대로 붙여넣고 Enter:
   ```
   /plugin marketplace add https://github.com/sodam-ai/SoDam-Agentic-Eng
   ```
   → "추가됨" 계열 메시지가 보이면 성공.
2. 설치:
   ```
   /plugin install sodam-agentic@sodam-agentic
   ```
   → "installed / 설치됨"이 보이면 성공.
   > ⚠️ **마켓플레이스 이름 주의(2026-07-27 확정):** 반드시 `sodam-agentic@sodam-agentic` 형태로 입력하세요. `@sodam`처럼 줄여 쓰면 실패합니다(과거 마켓플레이스 이름이 다른 형제 플러그인과 겹쳐 있던 문제를 이 날짜에 고쳤습니다 — [§16 업데이트 내용](#changelog)).
3. 확인: `/sodam-agentic:` 까지만 입력 → 명령 4개(`start`, `plan`, `review`, `log`)가 자동완성으로 뜨면 완료.

**(참고, 개발자 본인 로컬 테스트용)** 인터넷 주소 대신 내 컴퓨터 폴더 경로로도 등록할 수 있습니다:
```
/plugin marketplace add D:/AI_Dev_Work/2026y/26y_06m_26d_SoDam-Agentic-Eng
/plugin install sodam-agentic@sodam-agentic
```

### Codex — 설치
1. 이 저장소를 클론합니다:
   ```
   git clone https://github.com/sodam-ai/SoDam-Agentic-Eng
   ```
2. **내 프로젝트 폴더 안에서** 설치 스크립트를 실행합니다(클론한 경로로 바꾸세요):
   ```
   node C:\경로\SoDam-Agentic-Eng\codex\install.mjs
   ```
   > ⚠️ **폴더 실수 주의:** 터미널 도구에 따라 명령을 실행할 때마다 현재 위치가 사용자 홈 폴더로 초기화되는 경우가 있습니다. 반드시 **작업하려는 프로젝트 폴더로 먼저 이동(`cd`)한 뒤** 위 명령을 실행하세요. 그렇지 않으면 스킬·설정이 엉뚱한 폴더(예: 사용자 홈 폴더)에 설치됩니다.
3. 완료: 스킬이 내 프로젝트의 `.agents/skills/`에 복사되고, 안전 훅이 `.codex/hooks.json`에 등록됩니다.

> ⚠️ Codex에도 **같은 안전 훅(F4)·안전 기록(F6)이 그대로 등록됩니다**(F7, 2026-07-15 구현). 계획(F2)·검토(F3) 스킬도 동일하게 동작합니다. 다만 **Codex 화면에서 확인(ask) 창이 실제로 뜨는지는 아직 사람이 직접 확인하지 않았습니다** — 자세히: [§10 보안·데이터 흐름](#security-data-flow), [§17 현재 개발 상태](#dev-status).

<a id="usage"></a>
## 5. 실행·사용·작동 방법 (단계별)

**실행(설치 직후 켜기):**
1. `/sodam-agentic:start` 입력 → "AI에게 일 시키는 4단계" 온보딩을 읽습니다.
2. (권장) `/init`을 한 번 실행 → AI가 현재 폴더(프로젝트)를 인식합니다. *초보자가 가장 잘 건너뛰는 단계입니다.*

**사용(사람이 하는 것):**
3. **자연어로 시키기:** 예) "메모장 웹페이지 만들어줘". 확인·진단 명령부터 앞세울 필요 없습니다 — 그냥 시키는 게 먼저입니다.
4. **계획 확인:** AI가 코드를 짜기 전에 "①무엇을 ②왜 ③완성기준" 계획을 보여주면, 읽고 **"네/진행"**으로 승인합니다.
5. **검토:** 작업이 끝나면 "무엇을·왜 바꿨고 위험은?" 요약을 읽고 사람이 최종 판단합니다.

**작동(내부에서 자동으로 일어나는 것):**
6. AI가 파일을 쓰거나 명령을 실행하려는 **매 순간마다**, 소담의 안전 훅이 먼저 끼어들어 안전/확인/차단을 판정합니다([§9 아키텍처](#architecture)의 "판정 흐름" 참고). 사람이 아무것도 안 해도 항상 자동으로 동작합니다.

> 이 도구의 **아키텍처(구성요소·훅 실행 흐름)**가 궁금하면 → [§9](#architecture), **보안/데이터 흐름**이 궁금하면 → [§10](#security-data-flow).

## 6. 명령어 목록

| 명령 | 언제 쓰나 |
|---|---|
| `/sodam-agentic:start` | 처음 시작·온보딩 안내 |
| `/sodam-agentic:plan` | "계획 먼저" 기능을 직접 호출(보통은 자동 발동) |

> 형식은 `/플러그인이름:명령`입니다(2026-07-18부터 짧은 형태로 정리 — 예전엔 `/sodam-agentic:sodam-agentic-start`처럼 이름이 겹쳐 길었습니다). 새 대화창을 열고 `/sodam-agentic:`까지만 입력해도 4개가 목록으로 뜹니다.

<a id="workflow"></a>
## 7. 워크플로우 (작동 흐름)

```
[시작] /sodam-agentic:start  →  안전 켜짐 + 4단계 안내
   │
   ▼
[계획 먼저]  "만들어줘"  →  AI가 계획 제시  →  당신이 승인
   │
   ▼
[실행]  AI 작업  ──(위험 시)──▶  [안전]  자동 차단 / 확인
   │
   ▼
[검토]  무엇을·왜·위험  요약  →  당신이 판단  →  완료
```

> **발동 확인법(2026-07-26 추가):** 계획 먼저(F2)가 실제로 작동하면 응답 맨 위에 `🚀 소담 — 계획 먼저`가, 변경점 검토(F3)가 작동하면 `🔍 소담 — 변경점 검토`가 뜹니다. 이 문구가 안 보이면 다른 스킬에 밀려 F2/F3가 발동하지 않은 것이니, 그 자리에서 "계획 먼저 보여줘" / "검토해줘"라고 직접 요청하면 됩니다.

핵심 원칙: **"AI가 다 알아서"가 아니라, 사람이 운전석.**

<a id="architecture"></a>
## 9. 아키텍처

이 플러그인은 **서버·DB·로그인이 없는, 순수 로컬 도구**입니다. 구성요소는 이렇습니다:

| 구성요소 | 파일 | 역할 |
|---|---|---|
| 매니페스트 | `.claude-plugin/plugin.json`, `marketplace.json` | Claude Code에 "이 폴더가 플러그인"이라고 알려주는 설명서 |
| 온보딩 (F1) | `commands/start.md` | `/sodam-agentic:start` 슬래시 명령 정의 |
| 계획·검토 (F2·F3) | `skills/plan/`·`skills/review/`(자동 발동) + `commands/plan.md`·`commands/review.md`(수동 호출) | 새 작업 요청·변경 완료 시 자동 발동 + 직접 호출도 가능 |
| 검토 보조 에이전트 | `agents/easy-reviewer.md` | 변경이 많을 때 F3가 위임하는 **읽기 전용** 서브 AI |
| 안전 훅 (F4) | `hooks/hooks.json`(배선표) + `hooks/guard.mjs`(판정 로직) + `hooks/delegate.mjs`(형제 감지) | Bash·PowerShell·Write·Edit 실행 **직전**에 항상 개입 |
| 안전 규칙 데이터 | `data/agentic-rules.json` | 코드 수정 없이 조정 가능한 규칙 값 |
| 안전 기록 (F6) | `hooks/guard.mjs`의 `decide()` 내부 로직 + `commands/log.md` | 확인(ask)·차단(deny) 판정마다 `~/.sodamagentic/safety-log.jsonl`에 기록, 명령으로 조회 |
| Codex 지원 (F5) | `codex/install.mjs` | 마켓플레이스가 없는 Codex용 별도 설치기(스킬을 파일로 복사) |
| Codex 안전 패리티 (F7) | `codex/install.mjs`가 `.codex/hooks.json`에 등록 | 새 안전 로직을 따로 만들지 않고 **같은 `hooks/guard.mjs`를 Codex에도 그대로 등록**(기존 설정 있으면 병합) |

### 안전 훅(F4) 판정 흐름

```
Claude Code가 도구(Bash·Write·Edit 등)를 실행하려는 순간
        │
        ▼
   hooks/guard.mjs 가 먼저 판정 (PreToolUse = "실행 직전")
        │
        ├─ 안전(safe)          → 그냥 통과
        ├─ 확인 필요(ask)       → "정말 진행할까요?" 질문
        ├─ 위험(deny)          → "막았어요" (형제 SoDamHarness가 있으면 겹치는 항목은 위임)
        └─ 치명(catastrophic)  → "막았어요" (형제 유무와 **무관하게 항상** 차단)
```

- `hooks/delegate.mjs`의 `isHarnessAlive()`가 형제 플러그인 **SoDamHarness**의 존재를 확인합니다.
- Harness가 있으면 "겹치는" 위험(재귀 삭제·민감 경로 등)은 Harness에 넘겨 확인창이 두 번 뜨지 않게 합니다(Harness는 자동 백업·되돌리기까지 더해줍니다).
- **단, 되돌릴 수 없는 치명 명령과 자동 실행 설정 파일(`.mcp.json`)은 Harness 설치 여부와 무관하게 이 플러그인도 항상 자체적으로 막습니다** — 형제가 없거나 그 기능이 없을 때를 대비한 이중 안전장치입니다.
- **확인(ask)·차단(deny) 판정은 F6에 의해 `~/.sodamagentic/safety-log.jsonl`에 자동 기록됩니다**(안전하게 통과한 작업은 기록 안 함, 비밀값은 저장 전 자동으로 가려짐). 조회는 [`/sodam-agentic:log`](#commands).

<a id="security-data-flow"></a>
## 10. 보안·데이터 흐름

- **이 플러그인이 읽는 것:** Claude Code가 실행하려는 도구 이름과 인자(예: 실행할 명령어 문자열, 쓰려는 파일 경로)뿐입니다. 이 정보는 표준입력(stdin)으로 훅에 전달됩니다. 그 외 파일 내용이나 대화 내용을 따로 들여다보지 않습니다.
- **이 플러그인이 절대 하지 않는 것:** 자체 네트워크 요청(외부 서버로 전송) · API 키·비밀번호·토큰 저장 또는 기록 · 외부 코드 자동 실행. (자기보안 자가검증 결과 0건 — `hooks/_selftest.mjs`)
- **영구 데이터(F6):** 안전 훅이 **확인(ask)·차단(deny)** 판정을 내릴 때만 `~/.sodamagentic/safety-log.jsonl`(내 컴퓨터 사용자 폴더, 플러그인 개발 폴더 밖)에 한 줄씩 기록을 남깁니다. 기록 항목은 `{판정, 대상, 이유, 시각}`이며, 대상 문자열에 비밀값 패턴(API 키 등)이 있으면 저장 전 자동으로 `[REDACTED]`로 가립니다. **안전하게 통과한 작업은 기록하지 않습니다.** 이 기록은 외부로 전송되지 않고 내 컴퓨터에만 남으며, 기록 자체가 실패해도 안전 판정(차단/확인)에는 영향을 주지 않습니다. 조회는 [`/sodam-agentic:log`](#commands) 명령입니다.

### 실제 판정 예시

| 단계 | 예시 상황 | 실제로 뜨는 안내(요약) |
|---|---|---|
| ✅ 안전(통과) | 새 파일 만들기, 일반 설정값 변경 같은 평범한 작업 | (아무 메시지 없이 그냥 진행) |
| ❓ 확인(ask) | 파일 하나 삭제, 작업폴더 밖 쓰기 | "[소담 에이전틱] 되돌리기 어려운 작업이에요… 정말 진행할까요?" |
| ⛔ 차단(deny) | 비밀 값 노출 우려가 있는 작업 | "[소담 에이전틱] 비밀값이 노출될 수 있는 작업이라 막았어요…" |
| ⛔ 차단(deny) | 폴더 통째 삭제 | "[소담 에이전틱] 폴더를 통째로 지우는 작업은 안전하게 막았어요…" |
| ⛔ 차단(deny) | `.claude/settings.json`의 MCP 활성·권한·훅 경로를 바꾸거나 지우기(2026-07-27) | "[소담 에이전틱] AI 안전장치 자체를 바꾸는 항목이라 막았어요…" (그 외 일반 설정 변경은 여전히 확인만) |
| ⛔ 차단(deny) | `.mcp.json`(진짜 MCP 서버 실행 설정 파일)을 새로 만들거나 바꾸기(2026-07-27) | "[소담 에이전틱] 이 파일은 Claude Code가 자동 실행할 MCP 서버를 정의하는 곳이라 막았어요…" |
| ⛔ 차단(항상, 치명) | 되돌릴 수 없는 파괴적 명령, 또는 출처를 확인하지 않은 외부 코드를 곧바로 실행하는 패턴 | "[소담 에이전틱] 되돌릴 수 없는 위험한 명령이라 막았어요…" |

> 이 표는 이 저장소의 실제 코드(`hooks/guard.mjs`)에 있는 문구를 그대로 옮긴 것입니다 — 과장 없이, 실제 동작 그대로입니다. `[소담 에이전틱]` 접두사는 SoDamHarness 등 형제 플러그인과 동시 설치돼 훅이 함께 발동해도 어느 플러그인이 막았는지 바로 구분되도록 붙인 출처 표시입니다.
>
> **왜 `.mcp.json`이 특별히 중요한가:** `.mcp.json`은 Claude Code가 폴더를 열 때 자동으로 시작할 프로그램(MCP 서버) 목록을 정의하는 파일입니다. 이 파일의 내용이 원치 않게 바뀌면, 다음에 이 폴더를 열 때 사용자가 의도하지 않은 프로그램이 자동으로 시작될 수 있습니다. 그래서 이 파일은 내용과 무관하게 **항상 통째로 차단**하고, 정말 필요하면 사용자가 직접 편집기로 열어 수정하도록 안내합니다.
> **일관성 보강:** "AI에게 직접 명령어로 시켜서" 같은 방식으로도 위 판정을 피해 갈 수 없습니다 — 자연어로 부탁하든, 명령어를 직접 지정하든 동일한 기준으로 검사합니다.

## 11. 제거 방법 (Uninstall)

**Claude Code:**
1. 입력칸에 `/plugin uninstall sodam-agentic` (또는 마켓플레이스 화면에서 제거 선택).
2. 확인: `/sodam-agentic`를 쳐도 명령이 더는 안 뜨면 제거 완료.

**Codex:**
- 설치가 "파일 복사" 방식이므로, 내 프로젝트의 `.agents/skills/` 폴더에서 소담 관련 스킬 폴더를 직접 삭제하면 됩니다.

**남는 데이터(중요):** 플러그인을 제거해도 안전 기록 파일 `~/.sodamagentic/safety-log.jsonl`은 **자동으로 지워지지 않습니다**(플러그인 폴더 밖, 사용자 홈 폴더에 저장되기 때문입니다). 완전히 지우고 싶으면 이 파일을 직접 삭제하세요. Codex를 함께 썼다면 프로젝트의 `.codex/hooks.json`에 등록된 항목(F7)도 제거 후 그대로 남으므로, 지우려면 해당 JSON의 `PreToolUse` 항목을 직접 삭제하면 됩니다.

## 13. FAQ (자주 묻는 질문)

**Q. 이거 정말 안전한가요?**
A. 아니요, "100% 안전"은 아닙니다. "되돌릴 수 없는 위험은 막고, 나머지는 확인받는" 정도입니다. 최종 판단은 항상 사람이 합니다.

**Q. 돈이 드나요?**
A. 이 플러그인 자체는 **무료(Apache-2.0)**입니다. 다만 Claude/Codex를 쓰는 비용(AI 모델 사용료)은 Anthropic·OpenAI 약관을 따로 따릅니다.

**Q. Codex에서도 Claude Code와 똑같이 안전한가요?**
A. **같은 안전장치가 Codex에도 등록됩니다**(F7). 계획(F2)·검토(F3)·차단·안전 기록(F6)까지 같은 로직을 씁니다. 다만 **Codex에서 "확인해도 될까요?" 창이 실제로 뜨는지는 아직 사람이 직접 확인하지 않았습니다** — 100% 동등하다고 단정하지 않고 정직하게 남겨둡니다.

**Q. 막히거나 확인받은 기록을 나중에 다시 볼 수 있나요?**
A. 됩니다. `/sodam-agentic:log` 명령으로 최근 기록을 쉬운 한국어로 볼 수 있습니다. 단, 안전하게 통과한 작업은 기록되지 않고 막히거나(deny) 확인받은(ask) 것만 남습니다. 기록은 내 컴퓨터에만 저장되고 어디로도 전송되지 않습니다.

**Q. SoDamHarness 없이 써도 되나요?**
A. 됩니다. Harness가 없으면 이 플러그인의 "최소 안전 폴백"이 전체 모드로 작동합니다. 다만 자동 백업·되돌리기 같은 더 강한 기능은 Harness가 있어야 합니다.

**Q. 상업적으로 써도 되나요?**
A. 이 플러그인 자체는 Apache-2.0이라 상업 사용·재배포·서비스 운영 모두 가능합니다(NOTICE 파일 보존 조건). 단 Claude/Codex 모델 사용의 상업 조건은 각 제공사 약관을 확인하세요. 자세히 → [§15 라이선스](#license-legal).

**Q. 다른 5개 형제 플러그인도 꼭 설치해야 하나요?**
A. 아니요. 이 플러그인 혼자서도 최소 안전으로 작동합니다. 다만 SoDamHarness와 같이 쓰면 더 강력해집니다 → [§18 소담 패밀리](#family).

**Q. 제가 시킨 작업 내용이 어딘가로 전송되나요?**
A. 이 플러그인 자체는 네트워크 요청을 보내지 않습니다([§10](#security-data-flow)). Claude Code/Codex 자체가 AI 모델과 통신하는 것과는 별개입니다. (안전 기록(F6)은 전송이 아니라 **내 컴퓨터 파일에 저장**하는 것입니다.)

**Q. `.mcp.json`을 왜 무조건 막나요? 제가 진짜 MCP 서버를 추가하고 싶으면요?**
A. 이 파일을 편집기로 **직접(사람이 손으로)** 여시면 됩니다. 이 플러그인이 막는 건 "AI가 자동으로 이 파일을 대신 바꾸는 것"만입니다 — 왜 위험한지는 [§10](#security-data-flow) 참고.

## 14. 안전 주의사항 (꼭 지키기)

1. **`.claude/settings.json`의 민감 변경(MCP 활성·권한·훅 경로)을 확인(ask)에서 차단(deny)으로 승격.** 지금까지는 내용과 무관하게 항상 확인창만 떴는데, AI 안전장치 자체를 무력화할 수 있는 가장 위험한 변경이 확인창 하나로만 방어되고 있었습니다. 이제 이 항목들은 즉시 차단됩니다.
2. **같은 민감 항목을 "삭제"하는 경우도 차단 대상에 포함.** 앞선 보완은 "새로 추가"만 잡았고 "있던 보호 항목을 지우는" 경우는 놓치고 있었던 것을 실제 재현으로 발견·보완.
3. **마켓플레이스 이름 충돌 발견·수정.** 실사용 테스트 중 설치 자체가 실패하는 원인을 추적한 결과, 이 플러그인의 마켓플레이스 이름(`sodam`)이 다른 형제 플러그인과 겹쳐 있었던 것을 발견 → `sodam-agentic`으로 변경, 설치 명령을 `sodam-agentic@sodam-agentic`으로 전면 갱신.
4. **`.mcp.json`(진짜 MCP 서버 설정 파일) 보호 공백 발견·보완.** 실사용 테스트 중 `mcpServers`라는 민감 설정값이 실제로는 `.claude/settings.json`이 아니라 `.mcp.json`이라는 **완전히 다른 파일**에만 존재한다는 것을 공식 문서로 확인했습니다. 즉 지금까지 1번 항목의 보호는 존재하지도 않는 위치만 지켜보고 있었던 것 — 이제 `.mcp.json`은 내용과 무관하게 항상 차단됩니다.

**검증:** 자가검증 테스트가 67건 → 76건 → 78건 → **85건**으로 늘었고, 직접 재실행해 **전부 통과 확인**(`PASS 85 / FAIL 0`). 구조 검증도 `PASS 13 / WARN 0 / FAIL 0`으로 정상(마켓플레이스 재설치까지 반영 완료).

</details>

- F2/F3를 스킬이 아닌 강제 훅으로 승격(자동 발동을 100% 보장) — 아직 착수 여부가 결정되지 않았습니다.
